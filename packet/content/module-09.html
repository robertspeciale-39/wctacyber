Module 9 teaches two things. First, the different kinds of IPv4 address and which ranges are reserved for special jobs. Second, the question that every later module quietly depends on: are these two hosts on the same network? Get that second skill solid and routing, ARP, and troubleshooting all get easier.

Three ways to send traffic

TypeGoes toExample
UnicastOne specific hostYour PC requests a web page from one server
BroadcastEvery host on the local networkAn ARP request, a DHCP Discover
MulticastA chosen group of hosts that joinedRouting protocol updates, streaming video

Broadcasts do not cross routers. That is a feature, because it keeps one network's chatter from flooding every other network. It is also why a router marks the edge of a broadcast domain.

Special addresses inside every network

In any IPv4 network, two addresses are spoken for and cannot be given to a host.

  • The network address has all host bits set to 0. It names the network itself. For 192.168.10.0/24 that is 192.168.10.0.
  • The broadcast address has all host bits set to 1. A packet sent there reaches every host on that network. For 192.168.10.0/24 that is 192.168.10.255.

Everything between them is a usable host address. For that /24, the usable range is 192.168.10.1 through 192.168.10.254.

Public and private ranges

Public addresses are unique across the whole internet. There are not enough for every device, so RFC 1918 sets aside three private ranges that anyone may use inside their own network. Routers on the internet will not forward them. Know these three cold.

RangeCIDRClass-style size
10.0.0.0 to 10.255.255.25510.0.0.0/8One huge network
172.16.0.0 to 172.31.255.255172.16.0.0/12Sixteen /16 networks
192.168.0.0 to 192.168.255.255192.168.0.0/16256 /24 networks, the home default

The middle one is the trap. 172.16 to 172.31 is private; 172.15.x.x and 172.32.x.x are public. Questions like to use 172.32.0.5 as bait.

Other reserved ranges

RangeNameWhat it means
127.0.0.0/8LoopbackThe device talking to itself. 127.0.0.1 tests the local TCP/IP stack and never touches the wire.
169.254.0.0/16Link-local / APIPAA client that could not reach a DHCP server gave itself this address.
224.0.0.0 to 239.255.255.255MulticastGroup addresses, never assigned to a single host.
255.255.255.255Limited broadcastBroadcast to the local network, used before a host has an address.

The diagnostic fact worth underlining: if a PC shows 169.254.x.x, DHCP failed. The PC is not broken and the cable may be fine. Check whether a DHCP server exists on that network and whether the PC can reach it.

Same network or not?

Two hosts are on the same network when their network portions are identical under the mask. The method works for any mask, and you will make it fast by repetition.

  1. Write the mask as a prefix and find where the network portion ends.
  2. Work out the network address for each host.
  3. Same network address means same network.
PC1  192.168.10.20   mask 255.255.255.0   network 192.168.10.0
PC2  192.168.10.77   mask 255.255.255.0   network 192.168.10.0   same, direct delivery
PC3  192.168.20.5    mask 255.255.255.0   network 192.168.20.0   different, needs a router

Masks that stop in the middle of an octet are where people slip. With a /26 mask, the networks in the last octet start at 0, 64, 128, and 192. So 192.168.1.70 and 192.168.1.120 are on the same /26 (both in 64 to 127), but 192.168.1.70 and 192.168.1.130 are not.

What "not the same network" costs you

When the destination is on the same network, the host sends directly. When it is on a different network, the host cannot reach it itself and hands the packet to its default gateway, a router. If there is no gateway, or a wrong one, traffic to other networks simply dies. Module 12 covers that failure in detail.

Segmentation means deliberately splitting one big network into several smaller ones. It shrinks broadcast domains, improves performance, and lets you apply security rules between segments. The router, or a Layer 3 switch, is what connects them.

  • Given two addresses and a mask, decide same network or different, then say what each case requires.

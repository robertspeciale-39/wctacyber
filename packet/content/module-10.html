IPv6 looks intimidating the first time and turns out to be mostly rules about writing things shorter. The competition is generous here: compression questions and address-type questions are close to free points once you know the rules. Learn them and take the points.

Why IPv6 exists

IPv4 has about 4.3 billion addresses and the world ran out of new ones to hand out. IPv6 uses 128 bits, which is enough for every device to have a unique public address, so the address-saving tricks of IPv4 are not needed.

Reading an address

An IPv6 address is written as eight groups of four hexadecimal digits, separated by colons. Each group is called a hextet and holds 16 bits. 8 hextets times 16 bits gives 128.

2001:0db8:acad:0001:0000:0000:0000:0001    full form, 8 hextets

The two compression rules

Writing all that out is miserable, so there are exactly two ways to shorten an address.

  1. Drop leading zeros in each hextet. 0db8 becomes db8, and 0001 becomes 1. A hextet that is all zeros becomes a single 0.
  2. Replace one run of consecutive all-zero hextets with ::. This can be done only once per address, otherwise you could not tell how many zeros each one stood for.
2001:0db8:acad:0001:0000:0000:0000:0001
2001:db8:acad:1:0:0:0:1        rule 1: leading zeros gone
2001:db8:acad:1::1             rule 2: three zero hextets become ::

To expand a compressed address, reverse it. Count the hextets you can see, subtract from 8, and that is how many zero hextets :: hides. In 2001:db8:acad:1::1 you can see 5 hextets, so :: is 3 of them.

Two traps: :: cannot be used twice, and you may only compress zeros, never other digits. If two runs of zeros tie, compress the leftmost one. If the choice is between a long run and a single zero hextet, the standard says use :: on the longer run.

Address types by prefix

Look at the start of an address and you can say what kind it is.

TypePrefixWhat it is
Global unicast2000::/3 (starts with 2 or 3)The public, routable address. The IPv6 equivalent of a public IPv4 address.
Link-localFE80::/10Works only on the local link. Every IPv6 interface has one. Routers do not forward it.
Unique localFC00::/7 (in practice FD00::/8)Private addressing for inside a site, like RFC 1918.
MulticastFF00::/8Group delivery. IPv6 has no broadcast; multicast does that job.
Loopback::1/128Same idea as 127.0.0.1.
Unspecified::/128"I have no address yet."

That "no broadcast" line is worth remembering. Things IPv4 did with broadcast, such as ARP, are done in IPv6 with multicast and a protocol called Neighbor Discovery.

Structure of a global unicast address

A typical address splits into a 48-bit global routing prefix given out by the ISP, a 16-bit subnet ID that you choose, and a 64-bit interface ID that identifies the device. That is why the standard LAN prefix is /64: 64 bits of network, 64 bits of host.

2001:db8:acad : 0001 : 0000:0000:0000:0001
|-- global --|  subnet  |------ interface ID ------|
   prefix (48)  ID (16)           (64)

How a host gets its interface ID

Three options: configure it by hand, get it from DHCPv6, or build it itself. EUI-64 is the self-building method. It takes the 48-bit MAC address, splits it in half, inserts FFFE in the middle, and flips the seventh bit (the universal/local bit).

MAC           00:1A:2B:3C:4D:5E
split         00:1A:2B  |  3C:4D:5E
insert FFFE   00:1A:2B:FF:FE:3C:4D:5E
flip 7th bit  00 = 00000000  ->  00000010 = 02
EUI-64        021A:2BFF:FE3C:4D5E

The bit flip is the step people forget. In the first byte it turns a leading 00 into 02.

Configuring it on a Cisco router

Router(config)# ipv6 unicast-routing
Router(config)# interface g0/0
Router(config-if)# ipv6 address 2001:db8:acad:1::1/64
Router(config-if)# ipv6 address fe80::1 link-local
Router(config-if)# no shutdown
Router# show ipv6 interface brief

ipv6 unicast-routing is the line that turns the router into an IPv6 router. Without it, the router has addresses but will not forward IPv6 between interfaces. Forgetting it is the most common IPv6 lab mistake. Setting the link-local address to something simple like fe80::1 makes show output readable.

Dual stack

Most networks are moving slowly, so most devices run dual stack: IPv4 and IPv6 both configured and both working side by side. It is the simplest transition method and the one the course expects you to name.

Before you move on

  • Expand fe80::1 to all eight hextets.
  • Say what FE80, FF02, and 2001 addresses are.
  • Give the command that makes a Cisco router forward IPv6.
  • Explain why the answer to "what is the IPv6 broadcast address?" is "there is none."

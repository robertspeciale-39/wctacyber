Module 19 is mostly vocabulary and sorting. It rewards precise definitions, and the questions cluster around two things: the two kinds of hypervisor and "who manages what" in each cloud service model. Get those two tables into your head and the module is done.

Virtualization

Virtualization lets one physical computer run several independent virtual machines (VMs). Each VM acts like a complete computer with its own operating system, but they share the real hardware underneath. The software that creates and manages them is the hypervisor.

  • The real machine is the host and runs the host OS (or the hypervisor directly).
  • Each virtual machine runs a guest OS.

The payoff is efficiency. A server that used to sit at 10% load running one job can run a dozen VMs, and you can copy, move, snapshot, and restore a VM as easily as a file.

If your CyberPatriot VM runs in VirtualBox on a school PC, that is a Type 2 hypervisor.

Virtual networks

VMs need to talk to each other and to the outside world, so hypervisors include virtual switches and virtual network cards. A virtual network behaves like a physical one, with VLANs, subnets, and firewall rules, but it is all software. Network designs can be built, changed, and torn down in minutes with no cabling. This is also why Packet Tracer itself is useful: it simulates a network in software.

A data center is a facility full of servers, storage, and networking that hosts these virtual machines. Cloud providers run very large ones.

What "the cloud" means

Cloud computing is renting computing resources over a network instead of owning them. Five traits define it: on-demand self-service, access over the network, shared resources, rapid elasticity (scale up and down fast), and metered, pay-for-what-you-use billing.

Local or cloud?

Scenario questions test whether you can tell where a resource lives. A file on your computer's hard drive is local. A Google Doc is in the cloud. A virtual server running on your own school's hardware is local virtualization, not cloud, even though it is virtual. Do not treat "virtual" and "cloud" as synonyms: virtualization is a technology, and cloud is a delivery model that usually relies on it.

Round 1's quiz comes from Modules 3 through 7, and this is the first of them. Wireless is also the module with the most guaranteed security question in the whole course, so read the security section twice.

How a client finds a network

An access point broadcasts a beacon frame several times a second. The beacon carries the SSID, which is just the network's name, plus what security the AP expects. Your phone hears beacons from every AP in range and shows you the list.

When you pick one, the client goes through three steps: it discovers the AP, it authenticates (proves it is allowed on), and it associates (registers with that AP so frames can be delivered to it). Only after association does the client usually ask for an IP address by DHCP.

Note the order, because it explains a symptom you will see in labs and in real life. A client can be associated to Wi-Fi and still have no internet, because association is a Layer 2 event and addressing is Layer 3. "Connected, no internet" almost always means DHCP failed or the gateway is wrong, not that the Wi-Fi is broken.

Channels and interference

2.4 GHz travels farther and goes through walls better. It is also crowded, and it only has three channels that do not overlap: 1, 6, and 11. 5 GHz has far more non-overlapping channels and much more bandwidth, but the range is shorter and walls hurt it more.

Two APs near each other on the same channel will interfere. So will a microwave, a cordless phone, and a poorly shielded monitor, all of which sit in the 2.4 GHz band.

The security ladder

Memorize this order. It is the single most predictable question in Module 3.

StandardStatusWhat to know
WEPBrokenCracked in minutes with free tools. Treat it as no security at all. If you see it on a quiz, it is the wrong answer.
WPAObsoleteA patch on top of WEP's hardware. Better, still not acceptable.
WPA2AcceptableAES encryption. The realistic baseline, and what most Packet Tracer labs will ask for.
WPA3Current bestStronger key exchange, protects against offline password guessing. The right answer when it is offered.

So the ordering is WEP < WPA < WPA2 < WPA3. When a question asks for "the most secure option available," pick the furthest right one in the answer list.

Two things that are not security

Hiding the SSID stops the network name from appearing in the beacon. It does not encrypt anything, and any client that connects still announces the name in the clear. Anyone with a free packet capture tool sees it in under a minute.

MAC address filtering lets you list which devices may associate. MAC addresses are sent unencrypted in every frame and can be changed in software in about ten seconds. It stops a curious neighbor and nobody else.

Both are speed bumps. Neither is a control. Say it that way if a question asks you to evaluate them, because the exam wants you to know the difference between inconvenience and protection.

The actual controls are: strong encryption (WPA2 or WPA3), a long passphrase, and changing the default administrator credentials on the AP itself. That last one matters more than students expect. Default admin passwords for every consumer router model are published online.

Cellular, Bluetooth, and NFC

Know these by range and purpose rather than by specification:

  • Cellular covers miles, run by a carrier, used when there is no Wi-Fi. A phone acting as a hotspot shares that cellular connection over Wi-Fi.
  • Bluetooth covers roughly ten meters and pairs two devices: headphones, keyboards, a car stereo.
  • NFC covers a few centimeters and needs near contact. Tap-to-pay and transit cards.

The quiz pattern here is a scenario asking which technology fits. Range is almost always the deciding clue.

Module 12 is short and carries one of the most reliable troubleshooting patterns in the whole competition. A host that can reach its neighbors but nothing beyond them has a gateway problem, and you should be able to say so within about three seconds.

The decision every host makes

Before a host sends anything, it asks one question: is the destination on my own network? It answers by comparing the destination address to its own address under its own mask, exactly the skill from Module 9.

Destination isHost does
Local (same network)Sends directly to the destination. It needs that host's MAC address.
Remote (different network)Sends to the default gateway and lets the router take over. It needs the gateway's MAC address.

A host does not need to know how to reach a remote network. It only needs to know where the exit is.

The default gateway

The default gateway is the IP address of the router interface on the host's own network. It is the door out. By convention it is often the first or last usable address (.1 or .254), but that is habit, not a rule.

Two requirements that students forget. The gateway must be on the same network as the host, so a host at 192.168.10.5/24 cannot use a gateway of 192.168.20.1. And the gateway address must be the router's actual interface address, not a made-up one.

Routers are boundaries

A router connects different networks and keeps them apart. It does not forward broadcasts, so each interface is its own broadcast domain. It also makes a forwarding decision for every packet based on the destination's network. That is why the router's interface address on a LAN is also that LAN's gateway.

What the failure looks like

Memorize this table. These are the symptoms, ordered from "most local" to "most remote," and they tell you where the problem is.

SymptomPoints to
Cannot ping anything, even neighborsCable, interface down, or wrong IP/mask on this host
Can ping neighbors, cannot ping the gatewayWrong gateway address, or the router interface is down or misconfigured
Can ping the gateway, cannot ping other networksA routing problem on the router or beyond (Module 14)
Can ping local hosts, nothing outsideMissing or wrong default gateway
Can ping outside by IP, but not by nameDNS (Module 16), not routing

The bold row is the one the quiz writers love. If the question says "can communicate with devices on the same network but not with devices on other networks," the answer is the default gateway every time.

NAT in one idea

Private addresses (Module 9) cannot cross the internet. At the edge of the network, the router performs Network Address Translation: it rewrites the private source address to a public one on the way out, remembers the conversation, and rewrites it back on the return. That is how a whole building of devices on 192.168.x.x shares one public address. At this level, you need the concept, not the configuration: NAT is private-to-public translation at the boundary.

Gateway of last resort

You will see this phrase when you read a router's routing table in Module 14. It means the same idea one level up: the route a router uses when it has no specific match, the router's own "send it that way and hope" exit.

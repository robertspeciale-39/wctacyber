Binary and place value

Each position in a binary number is worth double the one to its right. An 8-bit group (a byte, or in networking an octet) has these values. Memorize this row. It should be automatic.

128   64   32   16    8    4    2    1       place values, left to right
 1     1    0    0    0    0    0    0       = 128 + 64 = 192

The leftmost bit is the most significant bit, because it is worth the most. Half of a byte (4 bits) is a nibble.

Binary to decimal

Add up the place values wherever there is a 1.

1 0 1 0 1 1 0 0
128 + 32 + 8 + 4 = 172

Decimal to binary

Work left to right through the place values. If the value fits in what is left, write 1 and subtract it. If not, write 0.

Convert 200:
128 fits   200 - 128 = 72     1
 64 fits    72 -  64 =  8     1
 32 no                        0
 16 no                        0
  8 fits     8 -   8 =  0     1
  4 no                        0
  2 no                        0
  1 no                        0
                            11001000

Check by adding: 128 + 64 + 8 = 200.

Hexadecimal

One hex digit is exactly 4 bits, so one byte is exactly two hex digits. That is why hex is used for MAC and IPv6 addresses: it is compact and converts cleanly.

To convert, treat each hex digit separately. 3C is 0011 then 1100, so 00111100, which is 60. Going the other way, cut a binary number into groups of four starting from the right, and convert each group.

Binary ANDing: finding the network address

This is the operation that turns an address and a mask into a network. Compare bit by bit: the result is 1 only if both bits are 1.

Address bitMask bitResult
000
010
100
111
Address  192.168.10.77    11000000.10101000.00001010.01001101
Mask     255.255.255.192  11111111.11111111.11111111.11000000
AND                       11000000.10101000.00001010.01000000
Network  192.168.10.64

Where the mask has 1s, the address passes through unchanged. Where the mask has 0s, the result is forced to 0. In effect, the mask keeps the network portion and wipes the host portion. That is all a "network address" is.

How to get fast

  • Drill the place-value row until you can write it without thinking.
  • Do ten conversions a day, both directions. Time yourself and beat yesterday.
  • Learn the eight mask values as a set.
  • Convert mask octets and common octets (192, 168, 10, 172, 16) until they are reflexes.

Before you move on

  • Convert 172, 10, 224, 77 to binary and 11010110, 01100100 to decimal.
  • Convert hex BE and 2F to binary and decimal.
  • Write a MAC address's first byte in binary.
  • AND 172.16.45.9 with 255.255.240.0 and get the network address.
